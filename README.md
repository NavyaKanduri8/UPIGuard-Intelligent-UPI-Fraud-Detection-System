# UPI Fraud Detection System

## Overview
This project detects fraudulent UPI transactions using Machine Learning.

## Technologies Used
- Python
- Flask
- MySQL
- Scikit-learn
- Bootstrap
- Logistic Regression

## Features
- User & Admin Login
- Fraud Detection
- Risk Analysis
- Transaction History
- Fraud Analytics Dashboard
- Payment Blocking

## Machine Learning Algorithm
- Logistic Regression

## Modules
- User Authentication
- Fraud Prediction
- Risk Evaluation
- Transaction Management
- Admin Dashboard

## Dataset
Credit Card Fraud Detection Dataset
